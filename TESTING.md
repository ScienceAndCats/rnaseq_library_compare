## Not executed here

The single skipped test is the **actual PyDESeq2 statistical-engine integration
test**, which requires `pydeseq2` (and its dependencies). This runtime did not
have those packages, and package installation could not be completed. No mock
p-values or replacement significance test were used. The code targets the
verified PyDESeq2 0.5.4 API. After creating the supplied environment on PACE, run:

```bash
python -m pytest -q
```

With PyDESeq2 installed, that test fits a synthetic paired count model and checks
fold-change direction, available p-values, and adjusted-p-value ranges. The CI
workflow also installs PyDESeq2 before running it.

No real user count matrices, reference FASTAs, or PACE compute nodes were
available for end-to-end validation. Conda environment resolution itself was
not tested on PACE. Upstream compatibility was established by source inspection
and synthetic format fixtures, not by claiming access to actual run outputs.
